# Simple Calculator

A terminal-based calculator project written in C.

## Compile

gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator

## Run

./calculator

## Supported Operations

- Addition
- Subtraction
- Multiplication
- Division
- Quit (option 0)

## Numeric Behavior

The numeric type and division behavior must be documented
according to the completed implementation.

## Known Limitations

Non-numeric input handling is outside the mandatory scope.
